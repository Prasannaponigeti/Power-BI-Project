🦄 Unicorn Companies Dashboard – Power BI Project
📌 Project Overview

The Unicorn Companies Dashboard is an interactive Power BI project designed to analyze global unicorn startups based on their funding, valuation, industry, investors, and geographic distribution.
This dashboard provides meaningful business insights through dynamic visualizations and KPIs, helping users understand trends in the startup ecosystem.

🎯 Objectives
Analyze unicorn companies across different industries and continents
Track total funding and valuation of startups
Identify top industries attracting investors
Visualize company distribution geographically
Compare valuation trends across regions

📊 Dashboard Features
KPI Cards
Total Funding
Total Valuation
Target Number of Startups
Visualizations
Industry-wise unicorn count
Funding by city using map visualization
Continent-wise company distribution
Investors by industry
Valuation analysis by continent
Funding vs valuation trends
Gauge chart for startup targets
Interactive Filters
Industry slicer
Dynamic filtering across visuals
🛠️ Tools & Technologies Used
Microsoft Power BI
Microsoft Excel
Data Modeling
DAX (Data Analysis Expressions)
Power Query

📂 Dataset Information
The project uses the following datasets:
Unicorn_Companies.xlsx
Funding.xlsx
Investors.xlsx

These datasets include:
Company details
Funding information
Investor details
Industry classification
Geographic data

📈 Key Insights
Fintech and E-commerce industries have the highest number of investors.
North America contains the largest share of unicorn companies.
Funding and valuation show strong growth trends across major startup hubs.
Artificial Intelligence and Cybersecurity sectors are rapidly expanding.

🚀 How to Use
Download the .pbix file
Open it using Microsoft Power BI Desktop
Refresh the datasets if required
Interact with slicers and charts to explore insights
